# danemalenfant.com

Source for [Dane Malenfant's academic website](https://danemalenfant.com), hosted with GitHub Pages and generated by Jekyll.

## Structure

- The primary pages are Markdown files in the repository root.
- Shared layouts and includes live in `_layouts/` and `_includes/`.
- Site-wide styles and interactions live in `assets/css/` and `assets/js/`.
- Publication figures, profile images, and social-preview assets live in `images/`.

Content and site-specific design are maintained by Dane Malenfant. The site began from the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) Jekyll theme; licensing details are available in [LICENSE](LICENSE).
